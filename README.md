# 🎵 MuseNest (Версия 0.1 - Минимально Рабочая)

Мощный кроссплатформенный инструмент для автоматического мониторинга дискографий любимых артистов в музыкальных базах данных (**Deezer**, **Spotify**, **MusicBrainz**), умного поиска лучших аудиозаписей на **YouTube** (с фильтрацией по длительности, стоп-словам) и локальной загрузки в **MP3** высокого качества.

---

## 🚀 Нововведения в Версии 0.1.7 (Лог Изменений)

* **Устранение критической ошибки 403 (Spotify Forbidden)**: Полностью переписан алгоритм поиска артистов. Больше никаких падений приложения, если у пользователя не заполнены или истекли ключи Spotify API! Поиск автоматически переключается на бесплатную базу Deezer, работающую без авторизации.
* **Индивидуальный выбор платформы**: Прямо в списке артистов добавлен выпадающий список (Deezer / Spotify). Теперь вы можете отслеживать популярных артистов через Spotify (для полной и точной метадаты, если есть Premium/ключи), а остальных — через Deezer.
* **Двойное сопоставление ID (Spotify ↔ Deezer)**: При поиске артиста система автоматически находит его аналог на второй платформе. В настройках (`config.json`) и дереве (`library.json`) сохраняются сразу оба ID: `spotify_id` и `deezer_id`.
* **Умное слияние конфигурации (Smart Merge) и защита от затирания**: Решена проблема оригинальной архитектуры, при которой ручное редактирование простого списка `artists.txt` стирало все богатые метаданные в `config.json`. Приоритет теперь отдается красивым распознанным именам в базе. Внедрена система самовосстановления (Self-Healing) — если `artists.txt` на диске пуст, он автоматически пересоздается из резервного файла `config.json`.
* **Автоматическая сортировка по Жанрам и Папкам**: Добавлена поддержка создания вложенных категорий (например: `Rock`, `Metal/Symphonic`). Прямо в карточке артиста можно ввести путь жанровой папки. Система **автоматически перенесет все скачанные треки этого артиста на жестком диске в новую вложенную папку** (в формате `save_folder/Жанр/Артист/Альбом/Трек.mp3`) и удалит пустые старые директории!
* **Интеллектуальный импортер медиатеки (`📁 Импорт папок`)**: Одно нажатие сканирует вашу папку сохранения:
  * Распознаются вложенные папки любой глубины.
  * Работает умная эвристика — система по каталогам вычисляет Имя исполнителя и Жанровый путь.
  * **Парсер свободных файлов**: Если треки были просто навалены в кучу в папку жанра в формате `Артист - Трек.mp3`, система выделит имя исполнителя, найдет его в Deezer, добавит в настройки и автоматически расставит все файлы по аккуратным вложенным полочкам.
* **Современные пилюли-игноры (Pill Buttons)**: Архаичные чекбоксы заменены на элегантные овальные бейджи. Они имеют деликатный темный стиль, а при активации подсвечиваются ярким неоново-красным цветом. Клик по игнору больше никогда не вызывает спонтанного закрытия/сворачивания карточки артиста!
* **Монолитный вложенный дизайн медиатеки**: Карточка артиста представлена как целостная плитка с мягким темным фоном. Раскрытие альбомов происходит физически **внутри карточки** на контрастном фоне. Слева от каждого альбома горит цветная акцентная полоса, отражающая статус готовности.
* **Светодиодный (LED) статус треков**: Каждая песня лишилась громоздких рамок и выводится в виде плоской интерактивной строки, перед которой горит яркий неоновый светодиод: 🟢 (Скачано), 🔴 (Ошибка/Пропуск), ⚪ (Ожидание). Текст трека окрашивается в тон его статусу.
* **Стабильное копирование логов**: Клик по строке логов мгновенно копирует ее в буфер обмена. На правом краю строки парит абсолютный бейдж **`Copied!`**. Копирование защищено от прерываний — даже при получении десятков новых логов в секунду, подсветка и бейдж удерживаются ровно 1.2 секунды!
* **Устранение миганий (Differential DOM)**: Как для логов, так и для дерева библиотеки внедрена технология сверки HTML-снимков. Контент в DOM перезаписывается только при реальном изменении данных, полностью убирая мерцание и сохраняя позицию прокрутки.
* **Абсолютное выравнивание в поиске**: Сетка выпадающего окна поиска переведена на Flexbox. Имена артистов выровнены слева, а подписчики, ID и интерактивные круглые кнопки 🎧 прижаты к правому краю, образуя идеальную вертикальную колонку.
* **Плиточный дашборд настроек (2х2)**: Настройки интервала, допуска, потоков и лимитов оформлены в виде крупных отзывчивых карт. Рамка карты мягко подсвечивается зеленым неоновым свечением при наведении, а вся плитка является кликабельной интерактивной кнопкой! В выпадающих списках устранен белый текст на белом фоне.

## ✨ Ключевые возможности

1. 📁 **Структурированный формат папок («Жанр / Артист / Альбом / Трек.mp3»):**
   - Автоматическая структуризация музыкальной коллекции по вложенным папкам жанров и альбомов.
   - Имена файлов и папок бережно очищаются от запрещенных операционной системой символов.

2. 🧠 **Умная дедупликация и экономия места (100% защита от дубликатов):**
   - **Один трек — один файл на диске:** Если трек присутствует и в сингле, и в полноценном альбоме, он скачивается **ровно один раз** в папку первого полноценного альбома.
   - **Логические ссылки:** В интерфейсе этот трек будет светиться зелёным (скачанным) во всех альбомах и синглах, где он присутствует, не занимая лишнего места на диске.
   - **Авто-сортировка и чистка:** Скрипт автоматически находит старые файлы (в корне или папках синглов), переносит их в новые папки альбомов, а опустевшие папки синглов удаляет.
   - **Решение проблемы маятника:** Логика приоритетов построена по нормализованному имени трека, что исключает бесконечный перенос файлов туда-сюда из-за разных ID релизов на сервисах.

3. 🚀 **Многопоточность нового поколения:**
   - **Параллельная загрузка:** Поиск на YouTube и скачивание треков выполняются параллельно (до 8 потоков в соответствии с настройками).
   - **Параллельный сканер (в 6 потоков):** Сбор треков и альбомов из сети Deezer/Spotify оптимизирован через пул потоков, благодаря чему дискография любого артиста собирается за 1–2 секунды вместо полуминуты.

4. 🌍 **Полная расширяемая локализация (RU / EN / Кастомные языки):**
   - Удобный выпадающий список выбора языков прямо в шапке интерфейса (выбор запоминается в браузере).
   - Все тексты (включая настройки, источники, плейсхолдеры и логи) полностью переведены.
   - **Кастомные переводы:** Пользователи могут самостоятельно создавать новые локализации, просто скопировав любой файл в `data/translations/` (например, создав `DE-Deutsch.txt`).
   - **Каскадный фоллбэк:** Если в пользовательской локализации пропущен какой-то ключ, интерфейс автоматически и безопасно подставит английский вариант — никаких пустых строк или ошибок в UI.

5. 🔴 **Интерактивная диагностика ошибок (`ERR-1` — `ERR-5` + подробный TODO-лист):**
   - Если трек не прошел фильтры, он загорается **тонкой красной обводкой** с кодом ошибки:
     - **`ERR-1`** — Не найдено подходящих результатов на YouTube.
     - **`ERR-2`** — Не подошло по времени (длительность отличается от оригинала больше допуска).
     - **`ERR-3`** — Отфильтровано стоп-листом блек-листа.
     - **`ERR-4`** — Ошибка загрузки или конвертации (обрыв соединения, блокировка YouTube).
     - **`ERR-5`** — Сетевой сбой или жесткий лимит запросов YouTube.
   - **Всплывающий TODO-список:** При наведении курсора на код ошибки выводится подробная пошаговая инструкция на выбранном языке, как решить эту конкретную проблему.

6. ⏹ **Экстренная мгновенная остановка:**
   - Прерывание текущего сканирования и загрузок в один клик. Работает молниеносно благодаря перехватчику логов `YtDlpAbortLogger` и progress-hook, выбрасывающим прерывание прямо внутри `yt-dlp`.

## 🛠️ Техническое описание архитектуры (для будущих разработчиков)

Инструмент построен по модульному принципу на связке **Flask (бэкенд)** и **Vanilla JS (фронтенд)**.

### 1. Архитектура работы с источниками (`core/source.py`, `core/spotify.py`)
- **`DeezerSource`**: Не требует авторизации. Использует общедоступное API `https://api.deezer.com`. Служит основным стабильным поисковым шлюзом по умолчанию. Извлекает число подписчиков (`nb_fan`).
- **`SpotifyClient`**: Работает через официальное API `https://api.spotify.com/v1`. Требует выполнения OAuth Client Credentials (`_auth()`). Если авторизация падает с ошибкой (например, из-за пустых/неверных ключей), это перехватывается на уровне роутера API и не приводит к падению бэкенда.
- **`MultiFallbackSource`**: Умный агрегатор источников. Сначала опрашивает Spotify (если авторизован), затем Deezer, и в крайнем случае — базу MusicBrainz.

### 2. Спецификация хранения артистов (`data/config.json` и `data/library.json`)
В версии 0.1.7 каждый артист в конфигурационном файле имеет следующую структуру:
```json
{
  "id": "spotify_id_или_deezer_id_или_имя",
  "name": "Официальное имя артиста",
  "source": "deezer",  // Источник для мониторинга: "spotify" или "deezer"
  "spotify_name": "Имя в Spotify", 
  "spotify_id": "46P740d5P5uXbS6nCq0lS7", // Уникальный 22-значный Base62 ID
  "deezer_id": "15100095",                // Числовой ID Deezer
  "genre_path": "Rock/Metal"              // Опциональный путь подпапок
}
```

Файл `library.json` хранит в себе снимок структуры дискографии артистов (альбомы, треки, длительность, флаги `downloaded`, `ignored`, `no_match` и коды ошибок `error_code`), которая динамически обновляется из выбранного источника.

### 3. Логика API Поиска (`/api/artist_search`)
Когда пользователь отправляет поисковый запрос:
1. Выполняется парсинг ввода (`src_mod.parse_input`). Распознаются регулярными выражениями ссылки Spotify, Deezer, чистые Spotify ID (ровно 22 символа, кроме чисто числовых) и Deezer ID (числа).
2. Если введен **Spotify ID / URL**:
   - Бэкенд запрашивает имя через клиент Spotify (если ключи активны).
   - Если ключей нет, используется резервное авторазрешение (или ID используется как временное имя).
   - На основе полученного имени выполняется мгновенный поиск в Deezer для сопоставления и сохранения `deezer_id`.
3. Если введен **Deezer ID / URL**:
   - Бэкенд получает имя из Deezer.
   - Выполняет поиск по этому имени в Spotify (если ключи активны) для заполнения `spotify_id`.
4. Если введено **обычное имя**:
   - Запрашивается Deezer API (лимит 8 результатов).
   - Для каждого результата в фоновом режиме (при наличии ключей) ищется пара на Spotify.
5. Возвращается обогащенный массив результатов с заполненными `spotify_id` и `deezer_id` для каждого совпадения.

## 🚀 Установка и запуск

### Зависимости:
Проект написан на **Python 3**. Для конвертации скачанных треков в формат `.mp3` на вашем компьютере должен быть установлен **ffmpeg** (путь к нему должен быть прописан в системной переменной PATH, либо исполняемый файл должен лежать в корне проекта).

### Установка библиотек:
```bash
pip install -r requirements.txt
```

### Запуск приложения:
```bash
python3 app.py
```
Сервер запустится по адресу `http://127.0.0.1:5000/` и автоматически откроет вкладку в вашем браузере по умолчанию.

#### Быстрый запуск кликом (на Windows и Linux):
- `run.bat` (Windows) или `run.sh` (Linux / macOS) — только запускают **`start.py`**.
- `start.py` сам проверяет канал, качает zip нужной ветки с GitHub (**git не нужен**), ставит зависимости и стартует `app.py`.

Канал обновлений — **`update_channel.txt`** в корне:

```
# stable  — только ветка main
# beta    — самая новая ветка на GitHub (по дате последнего коммита)
stable
```

## 📁 Папка пользовательских данных (`data/`)

При обновлении программы вы можете свободно заменять файлы кода, оставляя папку `data/` нетронутой — все ваши настройки сохранятся.

* **`translations/`** — Файлы локализаций (например, `RU-Russian.txt`, `EN-English.txt`). Формат файлов: `id:текст`.
* **`artists.txt`** — Простой текстовый список артистов (по одному на строку). Можно писать как имена, так и вставлять ссылки. Автоматически синхронизируется с `config.json`.
* **`blacklist.txt`** — Список слов-исключений для YouTube (по одному на строку). Видео с этими словами (например, `remix`, `live`, `cover`) будут игнорироваться.
* **`save_folder.txt`** — Путь к папке для сохранения скачанных треков.
* **`config.json`** — Системный файл конфигурации.
* **`library.json`** — База логического дерева альбомов, треков и статусов.
* **`tracks.db`** — База данных SQLite с историей загрузок.
