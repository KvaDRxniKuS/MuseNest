# 🎵 Spotify → YouTube Tracker

Мощный кроссплатформенный инструмент для автоматического мониторинга дискографий любимых артистов в открытых музыкальных базах данных (**Deezer**, **Spotify**, **MusicBrainz**), умного поиска лучших аудиозаписей на **YouTube** (с фильтрацией по длительности, блек-листу) и локальной загрузки в **MP3** высокого качества.

---

## ✨ Ключевые возможности

1. 📁 **Новый формат папок («Артист / Альбом / Трек.mp3»):**
   - Полная автоматическая структуризация музыкальной коллекции по папкам альбомов.
   - Имена файлов и папок очищаются от недопустимых системных символов.

2. 🧠 **Умная дедупликация и экономия места (100% защита от дубликатов):**
   - **Один трек — один файл на диске:** Если трек присутствует и в сингле, и в альбоме, и в сборнике, он физически скачивается **ровно один раз** в папку первого полноценного альбома.
   - **Логические ссылки:** В интерфейсе этот трек будет светиться зелёным (скачанным) во всех альбомах и синглах, где он присутствует, не занимая лишнего места на диске.
   - **Авто-сортировка и чистка:** Скрипт автоматически находит старые файлы (в корне или папках синглов), переносит их в новые папки альбомов, а пустые папки синглов удаляет.
   - **Решение проблемы маятника:** Логика приоритетов построена по нормализованному имени трека, что исключает бесконечный перенос файлов туда-сюда из-за разных ID релизов на сервисах.

3. 🚀 **Многопоточность нового поколения:**
   - **Параллельная загрузка:** Поиск на YouTube и скачивание треков выполняются параллельно (до 8 потоков в соответствии с настройками).
   - **Параллельный сканер (В 6 потоков):** Сбор треков и альбомов из сети Deezer/Spotify оптимизирован через пул потоков, благодаря чему дискография любого артиста собирается за 1–2 секунды вместо полуминуты.

4. 🌍 **Полная расширяемая локализация (RU / EN / Кастомные языки):**
   - Удобный выпадающий список выбора языков прямо в шапке интерфейса (выбор запоминается в браузере).
   - Все тексты (включая настройки, источники, плейсхолдеры и логи) полностью переведены.
   - **Кастомные переводы:** Пользователи могут самостоятельно создавать новые локализации, просто скопировав любой файл в `data/translations/` (например, создав `DE-Deutsch.txt`).
   - **Каскадный фоллбэк:** Если в пользовательской локализации пропущен какой-то ключ, интерфейс автоматически и безопасно подставит английский вариант — никаких пустых строк или ошибок в UI.

5. 🔴 **Интерактивная диагностика ошибок (`ERR-1` — `ERR-5` + TODO):**
   - Если трек не прошел фильтры, он загорается **тонкой красной обводкой** с кодом ошибки:
     - **`ERR-1`** — Не найдено подходящих результатов на YouTube.
     - **`ERR-2`** — Не подошло по времени (длительность отличается от оригинала больше допуска).
     - **`ERR-3`** — Отфильтровано стоп-листом блек-листа.
     - **`ERR-4`** — Ошибка загрузки или конвертации (обрыв соединения, блокировка YouTube).
     - **`ERR-5`** — Сетевой сбой или жесткий лимит запросов YouTube.
   - **Всплывающий TODO-список:** При наведении курсора на код ошибки выводится подробная пошаговая инструкция на выбранном языке, как решить эту конкретную проблему.

6. ⏹ **Экстренная мгновенная остановка:**
   - Прерывание текущего сканирования и загрузок в один клик. Работает молниеносно благодаря перехватчику логов `YtDlpAbortLogger` и progress-hook, выбрасывающим прерывание прямо внутри `yt-dlp`.

7. 🖥️ **Pixel-Perfect адаптивность (поддержка 21:9 ультрашириков):**
   - Сетка интерфейса жестко зафиксирована через CSS Grid `minmax(0, 1fr)` и `table-layout: fixed`. Элементы логов и таблицы больше никогда не растягивают и не ломают структуру на широких экранах.

## 🚀 Установка и запуск

### На Windows:
Просто запустите файл:
```cmd
run.bat
```
Скрипт использует системный Python (без тяжелых виртуальных окружений `venv`). При первом запуске он проверит наличие необходимых библиотек (`flask`, `requests`, `yt-dlp`) и при необходимости установит их локально для пользователя через `pip install --user`. Старт занимает доли секунды. Веб-сервер запустится и автоматически откроет страницу в браузере.

### На Linux / macOS:
```bash
chmod +x run.sh
./run.sh
```

## 📁 Папка пользовательских данных (`data/`)

Для того чтобы вы могли легко обновлять версию скрипта, не теряя свои настройки, списки артистов и базу скачанных треков, все пользовательские файлы вынесены в отдельную изолированную папку **`data/`**. 

При обновлении программы просто замените файлы кода новыми, а папку `data/` оставьте нетронутой.

### Содержимое папки `data/`:
1. **`translations/`** — папка с файлами локализаций (например, `RU-Russian.txt`, `EN-English.txt`). Формат файлов простой — `id:текст`.
2. **`artists.txt`** — список артистов для отслеживания (по одному на строку). Сюда можно писать просто имя группы (например, `Rammstein`) или вставлять прямые ссылки/ID со Spotify или Deezer. Файл можно свободно редактировать вручную в Блокноте.
3. **`blacklist.txt`** — список слов-исключений для YouTube (по одному на строку). Видео, в названии которых содержатся эти слова (например, `remix`, `live`, `instrumental`, `vocals only`, `vocals`), будут игнорироваться при поиске. Проверка полностью регистронезависима.
4. **`save_folder.txt`** — текстовый файл с путем к вашей папке сохранения треков (например, `D:\Music`). Вы можете вписать путь вручную, и скрипт будет сохранять все файлы именно туда. Также путь можно выбрать через кнопку `📁 Обзор` в интерфейсе, и файл обновится автоматически.
5. **`config.json`** — системный конфигурационный файл (ключи API Spotify, источник музыки, потоки, интервал фоновой проверки и т.д.).
6. **`library.json`** — файл логического дерева вашей медиатеки (содержит список альбомов, треков, статусы скачивания и ваши чекбоксы «Игнорировать»).
7. **`tracks.db`** — база данных SQLite с историей успешно скачанных треков.
8. **`cookies.txt`** — *(необязательно)* файл кук для YouTube (экспортируется через браузерные расширения вроде *Get cookies.txt LOCALLY*). Помогает избегать блокировок YouTube (Anti-bot).
